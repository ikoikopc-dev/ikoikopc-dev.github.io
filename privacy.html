プライバシーポリシー

clip-studio uploader（以下「本ツール」）は、運営者自身の YouTube チャンネルの管理だけに使う社内用ツールです。

取得する情報

Google の OAuth で許可された範囲（YouTube Data API：動画のアップロード、動画・再生リスト・サムネイルの管理）で、運営者のチャンネル情報と動画情報にアクセスします。

使い方

取得した情報は、運営者の動画のアップロード・公開予約・再生リストへの追加のためだけに使います。第三者への提供・販売・広告への利用はしません。

保存

認証用のトークンは運営者のパソコンの中だけに保存し、外部のサーバーには送りません。Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセスを取り消せます。

本ツールによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
